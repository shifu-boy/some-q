# some-q — Grade 7 Revision Quiz

Static quiz app (no build step) for Zambian Grade 7 revision.

- **English** — 200 verified multiple-choice questions
- **Integrated Science** — 109 verified multiple-choice questions
- **Mathematics** — 274 verified multiple-choice questions

Open `index.html` or visit the GitHub Pages site. Pick a subject, answer, get instant feedback with explanations. Best score per subject is saved in your browser.

Questions extracted from the Grade 7 revision kit docx banks; every kept question was machine-verified against its marking key.
